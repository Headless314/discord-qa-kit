# Discord QA Kit

A small Next.js app for preparing test profile data and checking a temporary inbox while doing authorized Discord QA or server onboarding.

## Safety boundary

This app does not create Discord accounts, submit registration forms, automate mass signups, or bypass verification. Use it only with Discord servers, accounts, and test environments you own or are authorized to test.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
